## About This Repository

This repository is my personal learning archive from the last two years. It contains course
notes, practice problems, experiments, assignments, and small projects collected while
learning from YouTube, Programming Hero, Phitron, Apna College, Udemy, and other resources.

It is not a polished product repository. It is a record of the process: starting with
programming fundamentals, building interfaces, learning backend development, and gradually
working towards full-stack development.

> Every folder represents a stage of learning, and every imperfect solution is part of the
> journey.

## Repository Tour

### `HTML & CSS`

My starting point for web development: HTML structure, CSS selectors, layouts, and styling
practice.

### `C Programming` and `C++`

Fundamental programming practice from book exercises and problem-solving sessions. The
practice includes:

- Conditions, loops, functions, arrays, strings, and mathematics
- Pointers, structures, and file handling
- Searching algorithms, vectors, bitwise operators, and array problems
- Kadane's algorithm and majority element

### `Apna College`

Course-based practice in three tracks:

- **JavaScript:** fundamentals, DOM manipulation, events, classes, asynchronous JavaScript,
  Fetch API, and mini-projects
- **C++:** data structures, searching, arrays, vectors, and algorithmic problem solving
- **Python:** data types, strings, collections, loops, functions, and OOP

### `PH` — Programming Hero

Milestone-based front-end learning with module exercises and assignments. This section
includes:

- HTML and CSS layouts
- Responsive design and practical UI building
- Tailwind CSS projects
- JavaScript fundamentals, ES6, arrays, loops, and conditions
- Module and milestone-based project practice

### `Phitron`

Practice and web-development tracks covering:

- C, C++, and Python fundamentals
- HTML, CSS, Bootstrap, and JavaScript DOM practice
- Django apps, templates, navigation, and projects
- A larger Django project with static assets, media, and a database

### `Chai-aur-Django`

A dedicated Django project where I practiced apps, templates, static and media files,
migrations, and Tailwind CSS integration.

### `Udemy`

Additional Python and Django practice, including Python basics, OOP, Django projects,
products, and an e-commerce-oriented project structure.

### `SASS` and `tailwindcss`

Focused styling experiments covering variables, nesting, mixins, functions, loops, partials,
imports, responsive utility classes, and compiled CSS.

## How to Use This Repository

1. Browse a topic folder that matches what you want to learn.
2. Read the notes and examples in the relevant module or lecture folder.
3. Run the code locally and experiment with it.
4. Compare the early exercises with the later projects to see the progress.

Some folders contain course-specific setup files or virtual environments. For the best
experience, open each project folder separately and follow its own setup instructions.
